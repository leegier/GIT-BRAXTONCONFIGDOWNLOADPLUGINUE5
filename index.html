Deterministic JSON Commands

NYGHTSHADE exposes structured commands that any AI system can generate

  "command": "bulk_update",
  "asset_type": "WeaponData",
  "filters": {
    "folder": "/Game/Weapons"
  },
  "changes": {
    "damage": "*0.9",
    "recoil": "*1.1"
  },
  "dry_run": true

How It Works

1️⃣ Install the Plugin

Copy NYGHTSHADE into your Unreal project's Plugins folder and enable it in the editor. No engine modifications required.

2️⃣ Connect Your AI Tool

Use Cursor, a local LLM, Python script, or any AI system that can generate structured JSON commands.

3️⃣ Let AI Automate

AI inspects your project, proposes changes, runs dry-runs, and executes validated operations — all while maintaining full audit logs.

4️⃣ Scale Your Production

What took hours of manual work now takes seconds. Focus on creative decisions while AI handles the repetitive tasks.
